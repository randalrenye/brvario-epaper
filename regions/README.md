# Pacotes de mapas

Este diretório é consumido diretamente pelo firmware.

- `catalog.json`: catálogo canônico das regiões disponíveis.
- `*.brmap`: pacotes binários otimizados para o ESP32-S3 e e-paper.

Não renomeie arquivos já publicados. Gere o catálogo somente depois que todos os
pacotes selecionados estiverem presentes e execute o validador da raiz antes de
publicar.

Documentação: [`docs/maps.md`](../docs/maps.md).
