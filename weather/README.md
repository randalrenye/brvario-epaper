# Rampas e meteorologia

Este diretório publica o catálogo de rampas usado para pesquisa, favoritos,
previsão meteorológica e seleção de mapas por raio.

- `catalog.json`: lista compacta carregada pelo ESP32.
- `catalog.schema.json`: esquema do catálogo.
- `site.schema.json`: esquema dos detalhes.
- `sites/`: um arquivo JSON por rampa.

Documentação: [`docs/weather.md`](../docs/weather.md).
